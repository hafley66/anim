## Problem/Context
- horn's d2 atlases only ever parsed under horn's lenient custom scanner. anim uses the real
  @terrastruct/d2 compiler, which rejects reserved keywords as id parts (link, class, style,
  label, shape, near, tooltip, width, height, direction, source, target). networking's L2
  container `link` had to be renamed `datalink`.
- horn networking.html was NOT the "tailscale vpn/fw/ts/tools" graph the prior summary assumed;
  it is a 60-rule DATALOG model (head :- body, % annotations, functor/arity ids). anim has no
  datalog ingest, so a converter was needed (Chris: "just convert it ur ai").
- The Write tool mangles literal U+2028/U+2029 chars placed in regex literals; use
  String.fromCharCode(0x2028) / .split().join() instead (fixed in bin/atlas-file.mjs safeJson).
- dist/atlas.js is tracked (CDN bundle); `dist/` gitignore only blocks NEW files. Must rebuild
  (npm run build:embed) after any embed.tsx/AtlasPanel change before regenerating standalone files.

## Solution/Approach
P1 generator: bin/atlas-file.mjs <graph.d2|.atlas.js> [-o] [--link] [--title] inlines
dist/atlas.js + {d2,tours,docs} as <script type="application/atlas+json"> child. embed.tsx
parses that type (raw-d2 back-compat kept), passes tours/docs to AtlasPanel. npm run atlas:file.
Generated atlases/*.html gitignored.

~/projects/anim/atlases/. networking (link->datalink), datalog-eval (clean). The datalog
networking.html SAMPLE+TOURS extracted and converted via new bin/datalog-to-atlas.mjs ->
atlases/networking-datalog.atlas.js (rules->edges, % folder->containers, %->#, functor/arity

## Key Insights
- One file = one graph. Standalone HTML inlines ~10MB bundle so it opens from file:// with no
  server. --link mode writes <script src=atlas.js> + drops the bundle beside it.
- container = parentOf(dotted id) in d2.ts; dropContainers strips compound nodes so ids() =
  leaves only. tag syntax is `# tag <id> : a, b` (colon). `# src` -> fs panel ref.
- Build embed BEFORE generating, or the standalone ships a stale renderer (hit this: groups
  panel missing until rebuild).
