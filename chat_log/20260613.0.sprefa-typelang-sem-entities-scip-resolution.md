## Solution/Approach
typegraph.rs:
- trait TypeLang { name, matches, extract -> TypeFacts }; RustTypes/KotlinTypes/TsTypes + type_langs() registry.
- TypeEntity { sym, name, kind, parent, file, line, ty }; EntityKind enum (struct|enum|trait|class|
  interface|alias|function|method|const) with .tag()/.is_callable(); sym = "file::kind::name" via mint_sym.
- TypeExpr { params: Vec<Vec<TypeRef>>, ret: Vec<TypeRef> }; TypeRef = Named|Resolved|Unresolved.
- Per-language entity passes (SEPARATE second parse, parallel to edge pass): ts_entities (arrow types
  for decls/default/arrow-consts/methods), rust_entities (syn, fns+impl methods, self dropped),
  kotlin_entities (types + functions). Lines: proc-macro2 span-locations (Rust), line_index byte-offset
  (oxc), node.start_position().row+1 (tree-sitter).
- Earlier in session: ts_edges gained function edges param/returns/uses (kind vocab now
  field|variant|impl|generic|param|returns|uses).
engine.rs:
- refresh_type_rels: registry dispatch (no if-chain), collect all TypeFacts (barrier), resolve corpus-global.
- resolve(file,name): scip_name_defs override (scip_ref def_file via scip_descriptor_name) else syntactic name-unique.
- 3 additive rels (type_edge/_rev stay name-keyed): type_entity(sym,name,kind,parent,file,line),
  type_sig(sym,slot,pos,ref) [arrow exploded, refs resolved], type_link(src,dst,kind) [SCIP-resolved sym->sym].
- TYPE_RELS grew to 5; reserved-name guard + type_rel_decls() updated.
anim-self.dl: node_ref + function span pins now from type_entity (kind="function"); kept regex pin for
.mjs + tokenize comment; kind tag for function nodes.
