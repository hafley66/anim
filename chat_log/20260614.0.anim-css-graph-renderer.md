Add a UI toggle for straight vs bezier. ## Key Insights
- Pure 4-inset anchor box `min(anchor a center, anchor b center)` = bbox of the two CENTERS → COLLAPSES to zero extent for colinear (same row/col) edges → they vanish. Fix was pad the box by --p and compute path in JS. A discrete-port approach may let CSS anchor() to specific sides instead.
- `content-visibility:auto` makes an off-screen node return `contain-intrinsic-size` for `offsetWidth` → poisons border math (caused a 10px short endpoint). REMOVED it; paint-virtualization deferred.
- `setPointerCapture` re-targets pointerup to the viewport, so tap must use the node captured at press-time, not ev.target (every click was reading as background→showAll).
- Hop superscripts widen a node AFTER layout, so cache-at-layout sizes are stale; read live `offsetWidth` in runEdges.
- cytoscape headless is the clean way to reuse all its layouts/plugins/grouping while rendering elsewhere.
- AtlasPanel already computes everything pure in core/ (cone, tours, layout tiers, heat); the backend only renders + applies classes.
